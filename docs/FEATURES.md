# Features

## MVP
- Local document upload
- PDF/DOCX/PPTX/TXT support
- Subject and semester organisation
- MongoDB vector retrieval
- Grounded RAG chat
- Evidence/source display
- Document deletion
- Indexing status
- Basic search
- Dashboard

## Phase 2
- Previous-year-question analysis
- Study mode
- Quiz generation
- Summaries
- Flashcards
- Exam revision

## Phase 3+
- OCR
- Hybrid retrieval
- Reranking
- Progress tracking
- Multi-user accounts
- Encrypted backups

All future study features should reuse the same document/evidence/RAG foundations.
